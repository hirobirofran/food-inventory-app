# Dependabot の更新 PR は、マイナー・パッチなら CI 通過でマージする

Dependabot の更新 PR をどこまで確認してからマージするかを決めた。マイナー・パッチ更新は CI（lint・test）が通ればマージできる。プレビューでの動作確認は、メジャー更新で、かつ実行時に動くパッケージ（next、react、googleapis、@google/genai）のときだけ行う。開発時にしか使わないパッケージ（eslint、typescript、vitest、@types/node）はメジャーでも CI だけで足りる。

理由: マイナー・パッチは互換性が保たれる前提で問題がほぼ出ず、確認を必須にすると更新が滞る。メジャーは CI が通っても実機で動かないことがあるので、プレビューで確かめる。
