# ドキュメントとコードコメントには版数や値を書かず、実物を指す

1. **ドキュメント（コードコメントを含む）には、版数や値を書かず、実物を指す。**
   最新は、コードで指す（出典 2）。
   コードコメントを含めたのは、オーナーの指示による（出典 1・2）。
2. **書きたい理由があるときは、オーナーに相談する。**
   たとえば、アーキテクチャの説明のために、その版だけを含めたい場合である。
   理由が無いのに、あちこちに版数や値を書くことはしない。

## 理由

必要もなく書いた版数は、実物とずれる（出典 1）。
意味もなく情報を二重管理（同じ情報を 2 か所に持つこと）すると、保守が大変になる（出典 2）。
