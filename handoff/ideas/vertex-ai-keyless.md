2. Vercel の OIDC Federation を GCP の WIF に信頼させる（Issue #6）。サービスアカウント鍵も GEMINI_API_KEY も不要になる
3. アプリの呼び出しを `@google/genai` の Vertex AI モード（project + location 指定）に切り替える。PR #13 で SDK は `@google/genai` になる予定なので、その後に着手すると差分が小さい
4. Google Sheets の認証も同じ WIF 経由にすれば GOOGLE_PRIVATE_KEY も消せる
