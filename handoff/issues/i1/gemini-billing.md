# Gemini API キーの発行元と課金

確認日: 2026-10-03

## キーはどこで発行しているか

- Google AI Studio の API キー一覧で管理している
- 本番・デモで使うキーは、AI Studio が自動作成した**無料枠プロジェクト**（表示名 "Gemini for food-inventory"）で発行する。請求階層は「無料枠」
- GCP プロジェクト側（Google Sheets 用のサービスアカウントがあるプロジェクト）にも Gemini キーが 1 本あるが、**使わない**。こちらは「Tier 1・前払い」で、前払い残高が 0 のため購入画面が出る
- 2026-10-03 に無料枠プロジェクトで新キーを発行し、本番に投入済み。旧キー（2026-04-18 作成）はデモ切替後に削除する

## 課金の仕組み（なぜ購入画面が出たか）

請求先アカウントには財布が 2 つある。

| 財布 | 対象 | 支払い |
|---|---|---|
| 後払い - Google Cloud サービス | GCP 全般（Vertex AI、Maps など） | 月次請求 |
| 前払い - AI Studio | AI Studio で発行したキーの有料利用 | 事前にクレジット購入 |

- Google Developer Program premium の月次クレジット（各 1 年有効、2026 年 2 月から毎月付与）は適用範囲が「Google Cloud Platform 全体、Google Maps API」で、**後払いの財布にだけ**自動適用される。AI Studio の前払い残高には使えない
- クレジットを Gemini に使いたいなら Vertex AI 経由に切り替える必要がある（SDK と認証が変わる）。Vercel からキー無しで呼ぶなら Issue #6 の Workload Identity Federation と組み合わせる
- 当面は無料枠キーで運用し、レート制限で困ったら Vertex AI 化を検討する

## 補足

- main のモデルは gemini-2.5-flash-lite（旧 SDK）。PR #13 で @google/genai と gemini-3.5-flash-lite に更新済みだが未マージ。2.5 系の停止時期が近い可能性があるため、インシデント対応の後に取り込む
