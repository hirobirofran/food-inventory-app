## 環境変数の UI が変わった

- 以前の「Sensitive」スイッチは無くなり、編集画面の **Type** で「Secret」か「Config」を選ぶ
- Secret: 保存後に誰も値を見られない。パスワード・API キー・トークンはこれ
- Config: メンバーが後から値を読める。NEXT_PUBLIC_APP_ENV のような公開値はこれでよい
- 「Needs Attention」バッジは「秘密に見える値が閲覧可能のまま」という警告。Secret で保存し直すと消える
- 値を変えても**再デプロイするまで反映されない**。保存後のトーストの Redeploy を押す

## Deployment Protection

- Vercel Authentication は ON、モードは Standard Protection

- 本番 URL とデモ URL は対象外。家族はアプリのパスワードだけで入れる
- Password Protection（Vercel 側のパスワード）は Pro プラン専用のため未使用
